## Микротест микрофонов (mictest6)

Прямая проверка микрофона платы без прошивки и без HA-пайплайна:

1. http.server 8899 + chime wav (github arturgadelshin/sound_ai_home
   awake_2.wav); платы видят сервер от src 192.168.210.81 (enp9s0)
2. aioesphomeapi connect → marker-файл `/config/.mictest_ready_<IP>`
3. Хост: `ss -K dst <IP> dport = 6053` — рвёт HA-сессию платы
4. Скрипт непрерывно накачивает `subscribe_voice_assistant` каждые 20мс
   (HA переподписывается за ~40мс — гонка; для упрямых плат двойной/тройной
   kill)
5. `send_voice_assistant_announcement_await_response(chime, timeout=12,
   start_conversation=True)` → чанки в handle_audio
6. Вердикт валиден только если в логах платы есть
   `Current client: aioesphomeapi` (grep)
7. После — sleep 3 + контрольный ss -K: HA забирает подписку обратно

## aioesphomeapi (46.2.0) — критичные детали API

- `subscribe_logs(cb, LogLevel.X)` — синхронный, возвращает stop-callable;
  без log_level → LOG_LEVEL_NONE → логов нет
- `device_info()` — async; `switch_command(key, state)` — синхронный
- `list_states` НЕТ — использовать `subscribe_states(cb)`
- `subscribe_voice_assistant(handle_start=, handle_stop=, handle_audio=)` —
  handle_start обязан вернуть 0
- `send_voice_assistant_announcement_await_response(media_id, timeout, text='',
  preannounce_media_id='', start_conversation=False)`
